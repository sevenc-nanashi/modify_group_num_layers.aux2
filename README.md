# modify_group_num_layers.aux2

グループ制御・画像合成などの「対象レイヤー数」をショートカットキーから変更できるようにするAviUtl2用の汎用プラグインです。

## 使い方

- このプラグインの操作は基本的には編集メニューとオブジェクトの右クリックメニューに追加されます。
- 「対象レイヤー数を増やす・減らす」：選択しているグループ制御系のオブジェクトの対象レイヤー数を増減します。
- 「対象レイヤー数を無制限にする」：選択しているグループ制御系のオブジェクトの対象レイヤー数を無制限にします。内部的には0を設定しています。
- 「対象レイヤー数を1にする」：選択しているグループ制御系のオブジェクトの対象レイヤー数を1にします。
- 「対象レイヤー数を選択しているオブジェクトに合わせる」：選択しているグループ制御系のオブジェクトの対象レイヤー数を、選択しているオブジェクトの一番下のレイヤーが含まれるように調整します。
  - この操作は標準の「対象レイヤー範囲を調整」と同じ動作をしますが、標準とは違いショートカットキーを割り当てることができます。

## インストール

[Releases](https://github.com/sevenc-nanashi/modify_group_num_layers.aux2/releases/latest)から`sevenc-nanashi.modify_group_num_layers-aux2-v{{version}}.au2pkg.zip`をダウンロードし、AviUtl2のプレビューにドラッグ&ドロップしてください。
